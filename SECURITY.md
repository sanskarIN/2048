# Security Policy

## Reporting a vulnerability

Please report potential security issues privately to **supportramsandesh@gmail.com**. Do not publish sensitive exploit details in a public issue before the maintainer has had a reasonable opportunity to review them.

Never include passwords, tokens, personal data, signing keys, or other secrets in reports.

## Scope

2048 Nova is offline-first and intentionally avoids analytics, advertising trackers, accounts, and cloud synchronization in the default build. External links are opened through platform handlers.
