# Changelog

All notable changes to this project are documented here.

## [Unreleased]

### Added
- Initial 2048 Nova Flutter codebase.
- Deterministic core move engine with persisted RNG state.
- Classic, Quick, Extended, Challenge, Endless, Target, Time Challenge, Move Limit, Daily, and Zen configurations.
- Responsive game UI with touch swipe and Arrow/WASD keyboard controls.
- Challenge timers and move-limit enforcement.
- Undo, hints, local save/resume, settings, statistics, and achievements.
- Guide, About, support, GitHub, LinkedIn, and Buy Me a Coffee integration.
- Light/dark/system themes, high-contrast option, reduced-motion preference, and semantic tile labels.
- Branded splash screen and original SVG logo.
- Automated engine, serialization, and widget smoke tests.
- Open-source governance and project documentation.

### Security
- No embedded credentials, analytics SDK, advertising tracker, or account system.
